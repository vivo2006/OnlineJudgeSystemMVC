CodeXpert · Original English demo problem

Sum two integers

Read two integers and print their sum.

Input

One line containing two integers a and b, separated by a space. Each integer is between −1,000,000 and 1,000,000.

Output

Print a single integer: a + b.

Example

InputOutput
2 3
5

Time limit: 1 second. Memory limit: 64 MB.
