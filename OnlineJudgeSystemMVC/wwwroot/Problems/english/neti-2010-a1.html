Note2 - Bitwise AND subarrays

CodeIT season 2024/2025, round 2

For CodeXpert, read from standard input and write to standard output. Use the time and memory limits displayed on the problem page.

K and L are competing again, this time using an array. K has an array of N integers, a1, a2, ..., aN, and L has chosen an integer M.

K chooses a non-empty subarray: a consecutive sequence of elements of the array. K wins if the bitwise AND of all elements in that subarray is at least M. L asks you to count the subarrays for which K wins.

Input

The first line contains N and M: the array length and the chosen integer. The second line contains the N integers in the array. The original statement names the input file note2.in.

Output

Print one integer: the number of subarrays whose bitwise AND is at least M. The original output filename is note2.out.

Constraints

  • 1 ≤ N ≤ 106
  • 1 ≤ M, ai < 260
  • Original time limit: 0.7 seconds.
  • Original memory limit: 256 MB.

Sample

Input

5 4
7 8 4 5 3

Output

5
