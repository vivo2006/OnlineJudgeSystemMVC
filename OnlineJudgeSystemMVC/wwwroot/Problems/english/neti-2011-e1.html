Think of a number

National Autumn Informatics Tournament, Shumen, 25-27 November 2011. Group E (grades 4-5). Original problem E2. Author: Zornitsa Dzhenkova.

For CodeXpert, read from standard input and write to standard output. Use the time and memory limits displayed on the problem page.

Bobi tells his brother Ivo: "I am thinking of a number. Divide it by a and subtract a from the result. Repeat the same two operations on the number you obtain, and the final result will be b. Can you find my number?"

Write a program think that finds Bobi's original number from the given values of a and b.

Input

Read the two integers a and b from standard input.

Output

Print the number Bobi originally chose.

Constraints

  • 1 ≤ a ≤ 100
  • 1 ≤ b ≤ 100

Sample

Input

7 33

Output
