Rectangle

National Autumn Informatics Tournament, Shumen, 25-27 November 2011. Group E (grades 4-5). Original problem E1. Author: Donka Darakchieva.

For CodeXpert, read from standard input and write to standard output. Use the time and memory limits displayed on the problem page.

A mathematics professor measured a rectangle with a tape measure. He calculated that its perimeter was x metres and y centimetres, and that one side was d centimetres longer than the other.

The absent-minded professor remembers x, y, and d, but has lost the measurements of the sides. Write a program rectangle that recovers them.

Input

The first line contains the integers x and y. The second line contains the integer d.

Output

Print the two side lengths on separate lines, each expressed in metres and centimetres. Each line must contain two non-negative integers separated by one space: metres first, then centimetres.

Constraints

Neither side is longer than 999,999,999 metres.

Sample

Input

11 40
70

Output

3 20
2 50
