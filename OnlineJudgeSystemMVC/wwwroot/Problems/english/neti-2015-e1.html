Maya the Bee

National Autumn Informatics Tournament, Shumen, 27-29 November 2015. Group E (grades 4-5). Original problem E1. Author: Pavel Petrov.

For CodeXpert, read from standard input and write to standard output. Use the time and memory limits displayed on the problem page.

Bees are sitting on three flowers arranged in a straight line, one metre apart. The left flower has no more bees than the middle flower, and the middle flower has no more bees than the right flower.

Maya, their leader, has determined that some bees can move so that all three flowers have the same number of bees. The bees need to conserve their energy. Before deciding which bees should move, Maya wants to find the minimum total distance they must fly.

Write a program bee that prints this minimum total distance in metres.

Input

The first line contains three integers A, B, and C, separated by spaces: the numbers of bees on the left, middle, and right flowers.

Output

Print one integer: the minimum total number of metres flown by all moving bees.

Constraints

  • 0 ≤ A ≤ B ≤ C ≤ 100
  • A + B + C > 0

Sample

Input

3 6 9

Output

6

Explanation

Move three bees from the rightmost flower to the leftmost flower. There will then be six bees on each flower. Each moving bee flies two metres, for a total of six metres.

Translation note: the original example explanation says three bees remain on each flower. This is an arithmetic typo; the correct count is six. The sample input and output are unchanged.
